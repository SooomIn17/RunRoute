# RunRoute

사용자가 직접 러닝 코스를 설계하고, 예상 거리를 확인한 뒤 원하는 경로를 따라 달릴 수 있도록 돕는 러닝 코스 설계 앱입니다.

## 프로젝트 소개

러닝을 하면서 원하는 거리만큼 달리고 싶어도,
출발 전에 직접 코스를 설계하고 해당 경로가 몇 km인지 확인하는 과정이 번거롭다고 느꼈습니다.

RunRoute는 이러한 불편함에서 출발한 프로젝트입니다.

사용자가 지도에서 직접 경유지를 선택해 러닝 코스를 만들고,
선택한 경로의 예상 거리를 확인할 수 있도록 하는 것을 목표로 합니다.

## 주요 기능

### 현재 개발 중

- 지도 화면 표시
- 지도에서 경유지 선택
- 선택한 경유지 시각화
- 경유지 간 경로 연결
- 예상 러닝 거리 계산

### 추후 구현 예정

- 현재 위치 표시
- 목표 러닝 거리 설정
- 경유지 되돌리기 및 초기화
- 러닝 코스 저장 및 불러오기
- 실제 도로 기반 경로 계산
- GPS 기반 실제 러닝 기록
- 계획한 코스 이탈 여부 확인

## 기술 스택

- React Native
- TypeScript

- react-native-maps

## 개발 환경

- Windows
- Visual Studio Code
- Expo Go
- iPhone

## 개발 목표

이 프로젝트를 통해 단순히 러닝 기록을 저장하는 앱이 아니라,
사용자가 직접 원하는 러닝 코스를 계획하고 거리까지 확인할 수 있는 서비스를 구현하는 것이 목표입니다.

또한 React Native를 활용한 모바일 앱 개발과
지도 및 위치 데이터를 다루는 경험을 쌓고자 합니다.
